Modificar atributos HTML

Con JavaScript podemos cambiar los atributos de un elemento (como src, href, alt o disabled). Se hace con el método setAttribute(nombre, valor) o accediendo directamente a la propiedad del elemento.

Ejemplo 1: cambiar la imagen (atributo src)


Ejemplo 2: desactivar un botón (atributo disabled)

Código explicado

// setAttribute(nombre, valor) cambia el valor de un atributo.
// Aquí cambiamos el atributo src (y el alt) de la imagen:
function cambiarImagen() {
  var img = document.getElementById("imagen");
  img.setAttribute("src", "https://placehold.co/300x160/7c3aed/ffffff?text=Imagen+2");
  img.setAttribute("alt", "Imagen de ejemplo 2");
}

// También podemos poner o quitar atributos booleanos como "disabled":
function alternarBoton() {
  var boton = document.getElementById("objetivo");
  if (boton.hasAttribute("disabled")) {
    boton.removeAttribute("disabled");
  } else {
    boton.setAttribute("disabled", "true");
  }
}
