Bienvenido al curso

Este curso te enseña a usar JavaScript para interactuar con los elementos de una página HTML. A lo largo de las distintas secciones verás, mediante ejemplos prácticos y comentados, cómo modificar el contenido, los estilos y los atributos de los elementos de forma dinámica desde el navegador.

¿Qué aprenderás?

  • Modificar contenido HTML con la propiedad innerHTML.
  • Modificar estilos CSS con la propiedad element.style.
  • Modificar atributos HTML con el método setAttribute().
