# Sistema de Control de Versiones · Práctica 1

Pequeña web para un curso de **JavaScript aplicado a interacciones con elementos HTML**, desarrollada siguiendo la metodología **Git Flow** y simulando un equipo de tres programadores.

## Contenido de la web

| Página | Qué muestra |
|---|---|
| `index.html` | Home con la descripción del curso |
| `contingut-html.html` | Modificar contenido HTML con `innerHTML` |
| `atributs-html.html` | Modificar atributos HTML con `setAttribute()` |
| `estils-css.html` | Modificar estilos CSS con `element.style` |

Para verla, abre `index.html` en el navegador.

## Reparto del trabajo

- **Usuario 1:** crea el repositorio, las ramas `main` y `develop` y la estructura inicial. Después hace el hotfix `hotfix/milloresV_1_0`.
- **Usuario 2:** `feature/contingutHTML` y `feature/atributsHTML`.
- **Usuario 3:** `feature/estilsCSS` y la release `release/v1.0`.

El nombre de cada usuario aparece en el mensaje de sus commits.

## Versiones

- `v1.0`: primera versión con las tres secciones.
- `v1.0.1`: hotfix con la mejora de la sección de contenido y la corrección de rutas del Home.
- `v1.0.2`: corrección de las rutas de las páginas de sección.
