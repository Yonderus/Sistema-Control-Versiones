Modificar contenido HTML

En JavaScript, la propiedad innerHTML permite leer y cambiar el contenido de un elemento HTML. Seleccionamos el elemento (por ejemplo con getElementById) y le asignamos un nuevo valor a innerHTML.

Ejemplo 1: cambiar texto

Soy un párrafo con su texto original.

Ejemplo 2: insertar HTML nuevo

Aquí aparecerá una lista.

Código explicado

// 1. Buscamos el elemento por su id
// 2. Le asignamos un nuevo contenido con innerHTML
function cambiarTexto() {
  document.getElementById("demo").innerHTML = "¡El contenido ha cambiado!";
}

// innerHTML también admite etiquetas HTML, no solo texto plano:
function crearLista() {
  document.getElementById("lista").innerHTML =
    "<ul><li>HTML</li><li>CSS</li><li>JavaScript</li></ul>";
}
